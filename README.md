# Job Skill Radar

Статус: у розробці.

## Проблема
Порівняння вимог вакансій зі своїми навичками займає час.

## Вхід
Текст вакансії, профіль навичок із резюме та побажання
щодо міста й формату роботи.

## Очікуваний результат
Збіги, прогалини, непідтверджені навички та рекомендація
з поясненням. Відсутність навички в резюме не означає,
що людина нею не володіє.

## Межі першої версії
Без автоматичного пошуку вакансій, Telegram-розсилки
та автоматичного надсилання відгуків.
